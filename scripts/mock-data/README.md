# 카이마루 빗물받이 1주 목업 데이터

이 데이터는 실제 설치된 빗물받이의 조사 결과가 아니라, KAIST 북측 카이마루
(N11) 주변에 빗물받이 4개가 있다고 가정한 시연용 데이터다. 카이마루의 기준
위치는 약 `36.37379, 127.35925`이며, 네 지점은 주변 진입로와 보행 동선에
자연스럽게 분산되도록 수십 미터 범위에 배치했다.

## 위치

| 키 | 가상 설치 위치 | 위도 | 경도 | 8월 22일 말 상태 |
|---|---|---:|---:|---|
| KM-N01 | 카이마루 북서측 진입로 저점 | 36.374060 | 127.358930 | 침수 위험 |
| KM-N02 | 카이마루 북동측 하역도로 | 36.374050 | 127.359520 | 정상 |
| KM-N03 | N11-N12 연결 보행로 | 36.373620 | 127.358780 | 정상 |
| KM-N04 | 카이마루-북측운동장 연결로 | 36.373310 | 127.359660 | 덮개 부분 막힘·점검 필요 |

카이마루가 N11 학생식당이며 북측 중앙에 있다는 점은 KAIST 캠퍼스맵을
기준으로 했고, 중심 좌표는 OpenStreetMap 기반 위치 정보를 참고했다.

- KAIST 캠퍼스맵: <https://www.kaist.ac.kr/site/map/index.html>
- 카이마루 위치 정보: <https://mapcarta.com/W78058765>

## 강우 및 센서 모델

사용자가 제공한 2026년 8월 16~22일 일강수량을 반영했다.

| 날짜 | 일강수량 | 모델링 결과 |
|---|---:|---|
| 8월 16일 | 10.5 mm | 오전부터 상승해 정오 무렵 중간 수위 |
| 8월 17일 | 3.9 mm | 전날 잔류수에 소폭 재상승 |
| 8월 18일 | 0 mm | 자연 배수 |
| 8월 19일 | 0 mm | 낮은 잔류 수위 유지 |
| 8월 20일 | 1.8 mm | 짧고 작은 반응 |
| 8월 21일 | 0.6 mm | 수위 변화가 거의 없음 |
| 8월 22일 | 30.4 mm | 오후에 큰 폭 상승, 두 저점은 경계 수준 |

관측 시각은 매일 `00:00`부터 `21:00`까지 3시간 간격이다. 총 데이터는 다음과
같다.

- 빗물받이: 4개
- 센서 관측: 지점당 56건, 총 224건
- 활성 알림: 2건
- `trash_level`: 현재 백엔드 호환을 위해 사용하는 계산 수위(cm)
- `cover_distance`: 덮개 막힘 감지 거리(cm)
- 배터리: 1주 동안 완만하게 감소
- 신호 세기: 지점별 기준값 주변에서 소폭 변동

일강수량만 제공됐기 때문에 시간대별 강우는 주간에 발생했다고 가정했다.
따라서 이 데이터는 기상 관측의 재현이 아니라 UI와 API 시연을 위한 합리적인
시뮬레이션이다.

## Render PostgreSQL에 적용

Render DB의 **Connect** 메뉴에서 `External Database URL`을 확인한 뒤 저장소
루트에서 실행한다. URL에는 비밀번호가 포함되므로 셸 기록이나 저장소에 남기지
않는 것이 좋다.

```bash
psql "<Render External Database URL>" \
  -v ON_ERROR_STOP=1 \
  -f scripts/mock-data/kaimaru_2026-08-16_22.sql
```

스크립트는 주소와 관측 시각을 기준으로 중복을 방지하므로 같은 DB에서 다시
실행해도 4개 지점과 224개 관측이 중복 생성되지 않는다. 실행 마지막에 지점별
관측 수, 기간, 최고 수위가 출력된다.

## 제거

목업 데이터를 전부 제거하려면 다음을 실행한다. 네 빗물받이에 연결된 센서
관측과 알림도 외래 키의 `ON DELETE CASCADE`에 의해 같이 제거된다.

```bash
psql "<Render External Database URL>" \
  -v ON_ERROR_STOP=1 \
  -f scripts/mock-data/cleanup_kaimaru_2026-08-16_22.sql
```
